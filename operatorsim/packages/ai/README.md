# packages/ai/

## What belongs here
- Prompt construction and response formatting.
- Narration, role dialogue, coaching feedback, and qualitative response evaluation.
- AI-layer adapters that translate between core state and model inputs/outputs.

## What does not belong here
- Canonical simulation rules or event scheduling logic.
- Frontend rendering code.
- Raw database schema definitions.

## Which future agents should work here
- AI Prompting Agent (primary)
- Voice Interaction Agent (speech turn formatting)
- Scoring Agent (evaluation mapping support)

## How this relates to the broader system
`packages/ai` interprets and communicates simulation context generated by `packages/core`. It enriches experience but does not decide simulation truth.
