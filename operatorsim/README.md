# OperatorSim Monorepo

OperatorSim is a mobile-web, voice-first operational simulation platform for SMB employee training.

This repository is intentionally documentation-first at this stage. It is organized so multiple future agents can work in parallel with minimal file overlap.

## Repository Layout

- `apps/` — deployable applications (starting with web client)
- `packages/` — shared libraries and system layers
- `docs/` — product and architecture documentation
- `prompts/agents/` — agent role briefs and working constraints

## Current Stage

This is the architecture initialization stage. No application logic, scripts, or dependency setup should be added until implementation agents begin their tracks.
