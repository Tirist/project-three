# prompts/agents/

## What belongs here
- Role-specific assignment documents for future automation agents.
- Constraints that keep agent work scoped and non-overlapping.

## What does not belong here
- Executable scripts and orchestration code.
- Product requirement docs better suited for `docs/`.

## Which future agents should work here
- Architecture Agent
- Program management/support agents coordinating multi-track delivery

## How this relates to the broader system
This folder reduces ambiguity in multi-agent collaboration by documenting ownership, handoffs, and guardrails.
