# prompts/

## What belongs here
- Human-maintained prompt assets and role instructions for AI-driven system components.
- Agent briefs that define responsibilities and boundaries.

## What does not belong here
- Runtime deterministic simulation rules.
- UI implementation code.

## Which future agents should work here
- AI Prompting Agent
- Architecture Agent (agent task definitions)

## How this relates to the broader system
`prompts/` defines the behavior framing for AI interactions while `packages/core` defines deterministic simulation truth.
