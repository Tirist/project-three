# MVP Scope

## In Scope

### Product Scope
- Mobile-web-first simulation experience.
- Voice-first interaction with tap/click fallback.
- One vertical: brewery/taproom operations.
- Single-session compressed game day (5–10 minutes).
- Event-driven day flow (not standalone quiz cards).
- End-of-session evaluation summary with coaching guidance.

### System Scope
- Deterministic simulation core for event triggers and outcomes.
- AI layer for dialogue, narration, and response evaluation support.
- Basic persistence for company config, sessions, events, and scores.

## Out of Scope

### Vertical/Market Expansion
- Multi-vertical industry packs.
- Marketplace for scenario packs.

### Platform Expansion
- Native iOS/Android apps.
- Offline mode.

### Advanced AI/Analytics
- Full autonomous AI game-master controlling simulation truth.
- Predictive workforce analytics.
- Deep personalization from large historical datasets.

### Enterprise Features
- SSO/SAML enterprise identity integration.
- Complex org hierarchy and permissions matrix.
- External compliance certification workflows.

## MVP Completion Signal
MVP is complete when a trainee can run a full brewery/taproom simulation session on mobile web, respond primarily by voice, and receive useful end-of-session coaching grounded in deterministic event outcomes.
